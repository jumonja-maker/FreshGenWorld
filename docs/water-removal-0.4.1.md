# 0.4.1-alpha.1: удаление системы воды

По запросу пользователя физически удалены Drainage/Hydrology 0.3.x, NaturalWaterTerrain и Watershed 0.4.0: модели, компиляторы, аквиферы, управление уровнями/обновлениями воды, подстановки биомов, вмешательства в деревья, структуры и замерзание. Удалены регистрации, связанные тесты и задания CI. Треугольная пересборка поверхности также отсутствует. Код сохранён только в архиве рабочей зоны и истории Git.

Рельеф возвращён к `4e50c82`, непосредственно перед первым водным коммитом `754b226`; опубликованный эталон — `dist/FreshGenerator-Fabric-26.3-0.3.6-alpha.1.jar`. Горы, континенты, биомные переходы, растительность, деревни и исходные маски речных долин этой версии сохранены. Вода снова штатная, мир не превращён в сухую карту.

Сохранено запрошенное отключение пещер через SurfaceOnlyCompiler и запрет карверов. VillageLakeMixin остаётся: он защищает деревни только от нативных **лавовых** озёр и существовал до системы воды. Нативные структуры остаются. Один публичный пресет — freshgenerator:world; для результата нужен новый мир, старые чанки не перестраиваются.

Проверка `python scripts/validate_native_water.py` требует совпадения игрового runtime с доводным выпуском, кроме отключения пещер. Ресурсы должны отличаться только четырьмя изменениями сплошной поверхности и одним маркером запрета карверов. Протоколы текущей сборки и короткого серверного запуска: `FreshGenerator-Workspace/water-removal-2026-11-14`.

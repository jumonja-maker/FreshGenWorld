# FreshGenerator в режиме «По умолчанию» — 0.7.1-alpha.1

Обычный стартовый режим Minecraft теперь создаёт мир FreshGenerator. Отдельный вариант в списке выбирать не требуется. Нативное название режима сохраняется; прочие стандартные варианты мира сохраняют свои настройки.

## Что было установлено по снимкам

Сохранение с пользовательским сидом `-3356723558182187063` содержит настройки генератора `minecraft:overworld`. Оно не использует `freshgenerator:highlands_v2`. Это проверено чтением `data/minecraft/world_gen_settings.dat` без записи в сохранение; снимки относятся к обычной генерации Minecraft.

Настоящий оторванный фрагмент из этого мира подтверждён чтением сохранённых блоков: 81 блок грунта в пределах `(136,97,468)..(141,105,472)`. Значит, это не просто рисунок шейдера. При запуске FreshGenerator на том же сиде и координатах получается другой рельеф: в региональной выборке 22704 точек высота составляет примерно Y49–90, горная маска равна нулю. Поэтому эти измерения нельзя выдавать за исправление форм на фотографиях.

Ранее мод добавлял пункт `freshgenerator:world`, а Minecraft начинал создание мира с `minecraft:normal`. Одного добавления в tag недостаточно для замены стартового выбора. Нативный `CreateWorldScreen.openFresh` выбирает NORMAL, а `WorldPresets.createNormalWorldDimensions` получает соответствующее определение из реестра.

## Изменение

- `data/minecraft/worldgen/world_preset/normal.json` содержит точную копию пресета FreshGenerator. У обычного мира теперь настройки поверхности `freshgenerator:highlands_v2`.
- В NORMAL tag больше не добавляется отдельный пункт FreshGenerator: `replace:false, values:[]`. Обычный список стандартных альтернатив сохраняется.
- Старый ключ `freshgenerator:world` остаётся доступен как идентификатор совместимости и для прежних серверных настроек.
- Все 59 runtime-классов, состав mixin, пещеры, ледники, деревья и рельеф принятой 0.7.0 сохранены побайтово. Меняются создание нового мира и метаданные пакета.

Уже сохранённый мир хранит свой генератор отдельно от пресета создания. Его чанки и настройки этим обновлением не переключаются. Для новой генерации нужно создать новый мир, оставив обычный режим «По умолчанию». Сервер также может использовать штатное значение `level-type=minecraft:normal` или не задавать тип вовсе.

Итоговый JAR: SHA256 `c0d0232cee6487fd9f4368778c0b45660e2bb9b69e69f771bf778d307fdb117a`. Архив выпуска: `FreshGenerator-Workspace/terrain-integrity-2026-11-15/final`.

- Сборка: 348 Java-тестов, ноль ошибок и пропусков.
- Пакет: все 59 runtime-классов и mixin побайтово совпадают с принятой 0.7.0. Все прежние 418 ресурсов, кроме NORMAL tag, сохранены; добавлен только alias пресета, итого 419 ресурсов. Поля пещер и ледников не изменены. Проверены точные метаданные нового Default и отсутствие переопределения `minecraft:overworld` noise settings.
- Переносимый валидатор прошёл с закреплённым текстовым снимком, исходным JAR и из другого каталога. Все пять испорченных пакетов отклонены, включая возврат ванильных настроек в alias, повторное добавление отдельного пункта FreshGenerator и изменение пещер с пересчитанным manifest.
- Три изолированные проверки Minecraft/Fabric с намеренно отсутствующим `level-type` в исходном `server.properties`. Аудитор прочитал фактический загруженный генератор, а также вызвал `WorldPresets.createNormalWorldDimensions` — ту же нативную фабрику, которая применяется при создании мира клиентом.

Minecraft-клиент не запускался и не управлялся автоматически. Пользовательские сохранения не перезаписывались. Эта проверка подтверждает выбор и сохранение генератора; она не является визуальной приёмкой всей генерации.

Пакет проверяет `python scripts/validate_default_world.py`. Отдельный эксперимент с ограничением верхних пещер не вошёл в выпуск: он не подтвердил связь входов с глубокой сетью. Принятые пещерные поля 0.7.0 сохранены; причина присланных снимков не приписывается этому эксперименту.
